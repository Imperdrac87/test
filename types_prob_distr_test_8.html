    🔄 With vs Without Replacement
    ✅ With Replacement — Binomial
    Each try is completely independent. The outcome of one try has zero effect on the next. The success chance stays exactly the same every time.
    🪙 Example: Flipping a coin 10 times. Each flip is fresh — the coin has no memory of previous flips. Getting heads on flip 3 does not change the odds for flip 4.
    🎯 Use when: Fixed number of tries, same success chance each time, tries are independent.
    ⚠️ Without Replacement — Hypergeometric
    Each draw changes what is left in the pool. After drawing a target, there is one fewer target remaining — so the next draw has slightly different odds.
    🃏 Example: Drawing 5 cards from a deck without putting them back. After drawing an ace, only 3 aces remain in 51 cards. The odds shift with every draw.
    🎯 Use when: Sampling from a finite group, no putting back, the sample is a meaningful fraction of the total.
    When does it matter? If your sample is less than 5% of the total pool, both methods give nearly identical results — use Binomial for simplicity. If your sample is a large fraction of the pool (say, drawing 40 from 50), without-replacement gives noticeably narrower results because extreme outcomes become harder to achieve.
