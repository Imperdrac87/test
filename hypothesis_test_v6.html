Hypothesis Testing Lab

How to use this lab

Core objective: practice concepts through gamified quiz sessions. This guide stays available from the top bar “Help” button.

1. Start a quiz session
Pick Practice, Standard, or Quick Review. The gamified quiz is the main learning path.
2. Answer with a 3-step rule
Identify curve (H0/H1), identify side (reject/fail), then choose the concept.
3. Use support tools only when needed
Simulation Lab and Reference Sheet are optional helpers, not the core assessment path.

Start options explained

Practice session (15 min)
Best for first attempts. More time to read graph regions and use hints.
Standard session (10 min)
Balanced pace once you know the flow of curve + side + concept.
Quick review (5 min)
Short refresher to rehearse key decisions under time pressure.
Simulation lab (guided walkthrough)
Interactive, untimed learning mode with split/combined views, one/two-tail toggles, and region quizzes.
Open reference sheet
Cheat sheet for definitions, formulas, interpretation, and common mistakes.

How the practice game works

Session mechanics
Each item shows a graph and a question. You answer by selecting the correct concept card.
Correct answers add points. Incorrect answers reduce attempts. Optional hints and explanations cost points.
Three learning levels
Stage 1: identify regions visually. Stage 2: apply to practical scenarios. Stage 3: reason about parameter changes and trade-offs.
Complete all stages before time or attempts run out to finish the session.

Statistical Testing Primer

The central question

Does the sample provide evidence of a real effect, or could the result be explained by random chance?

Null hypothesis (H0)

No effect / status quo

H0: μ1 = μ0
Alternative hypothesis (H1)

A real effect exists

H1: μ1 ≠ μ0

The test statistic (T)

The test statistic summarizes how far the observed result is from what H0 predicts.

Z = (x̄ − μ0) / (σ / √n)

Larger |Z| → more evidence against H0.

Decision rule

If p-value < α

→ Reject H0

|

If p-value ≥ α

→ Fail to reject H0
