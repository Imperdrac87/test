Statistical Testing Primer

The Central Question

Given sample data, can we conclude that a real effect exists in the population, or could our results be due to random chance?

Null Hypothesis (H₀)

"No effect" / "Status quo"

H₀: μ₁ = μ₀
Alternative Hypothesis (H₁)

"Real effect exists"

H₁: μ₁ ≠ μ₀

The Test Statistic (T)

A test statistic is a standardized value calculated from sample data. It measures how far the observed result is from what we'd expect under H₀.

Z = (x̄ - μ₀) / (σ / √n)

Larger |Z| → result is more extreme → more evidence against H₀

The Decision Rule

If p-value < α

→ Reject H₀

|

If p-value ≥ α

→ Fail to Reject H₀

Probability = Area Under Curve (Total = 1)
