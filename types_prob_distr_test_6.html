Probability Simulator

Predict, run, compare, explain, and transfer probability models through repeated random results.

Guided tour
Step 1. Choose the model

Start here. Pick the kind of result you want to explore, then choose one model. The example picker, summary, and chart all update from this choice.

  • Topic chips narrow the list so you can focus on one kind of question at a time.
  • Model cards load the simulator for that distribution and swap in matching examples.
  • The highlighted card shows the model the rest of the simulator is using right now.
Guided tour
Step 2. Start an example

This is the quickest path through the simulator. Pick a familiar example, start the simulation, and then add more results only if you want a clearer pattern.

  • 1. Pick an example gives you a fast starting point based on a familiar situation.
  • 2. Run the simulation creates the first batch of results from zero.
  • Add more results appears after that and extends the same run.
  • Experiment controls and model notes stay visible so you can connect each run to parameters, stats, and model assumptions.
