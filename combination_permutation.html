Permutations (Lock): order matters, no repeats. ⚡🌊🔥 is different from 🌊⚡🔥.
Combinations (Loot): order does not matter. {👑, 💰, 💍} is the same set as {💍, 👑, 💰}.
Goal: Calculate Security Complexity (Permutation without replacement)
We need to measure how secure this lock is.
Fill the slots one by one. Once you use a rune you cannot reuse it, so the number of choices shrinks.
This is a classic permutation: order matters, and there is no replacement.
Look at your Inventory below. You have 5 Runes to choose from.
Pick first rune...
Constraint: The lock has k=3 slots. We stop multiplying after 3 choices.
Permutation formula: P(n,k) = n! / (n - k)!. Here n = 5 runes and k = 3 slots, so P(5,3) = 5! / (5 - 3)! = 5 × 4 × 3 = 60 different passwords.
Teacher prompt: ask students to say out loud why ⚡🌊🔥 and 🌊⚡🔥 count as two different outcomes here.
Concept: Removing Redundancy (Combination without replacement)
The bag is a "Jumbler". Once items are inside, order is lost.
{Crown, Ring} is the same inventory as {Ring, Crown}. We must divide to remove these duplicate orderings.
This is a combination: order does not matter, and items are not replaced.
Fill the backpack (3 items) to see the math.
0 / 3 Items Picked
Combination formula: C(n,k) = n! / (k!(n - k)!). Here n = 5 items and k = 3 slots, so C(5,3) = 5! / (3! · 2!) = 10 different loot sets.
Teacher prompt: once the bag is full, ask students how many different orders exist for the same three icons and why they now count as one.
Application: Probability Spaces
Probability is just 1 ÷ Total Possible Outcomes in your sample space.

🔐 The Password Problem

There is only 1 correct sequence (e.g., ⚡🌊🔥). But we calculated 60 possible arrangements (Permutations).

Probability =
1 Correct Key 60 Total Keys
= 1.67%

Link back: the 60 comes from P(5,3).

🎒 The Loot Problem

You want the set {👑, 💰, 💍}. Order doesn't matter. We calculated only 10 possible unique sets (Combinations).

Probability =
1 Winning Set 10 Total Sets
= 10.0%
Insight: guessing a combination is easier than guessing a permutation because the sample space is smaller. Here the 10 comes from C(5,3), not from listing each order separately.
